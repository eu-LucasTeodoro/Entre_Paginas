# 📚 Entre Páginas

**Entre Páginas** é um aplicativo Android desenvolvido em Kotlin com Jetpack Compose, criado para ajudar leitores a descobrirem sua próxima leitura de maneira interativa e divertida.

O projeto surgiu de uma atividade de desenvolvimento mobile que propunha a criação de um aplicativo de escolha aleatória.

### ✨ Funcionalidades implementadas
- Estante virtual interativa.
- Simulação de sorteio com transição entre telas.
- Exibição do livro selecionado com capa, autor e sinopse.
- Botões interativos para marcar o interesse no livro e repetir o sorteio.

### 🛠️ Tecnologias
- Kotlin
- Jetpack Compose
- Android Studio
- Figma (prototipação)

### 🚧 Status do projeto
**Em desenvolvimento.**

Atualmente, estão implementadas as três telas principais do fluxo de sorteio, com um livro de exemplo. Futuramente, pretendo adicionar mais livros, filtros de leitura e novas funcionalidades.
